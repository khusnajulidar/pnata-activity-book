# Template Folder Halaman

Gunakan satu folder untuk setiap halaman:
- `README.md`: tujuan belajar, isi, aktivitas, sumber, keputusan, dan status.
- `assets/`: bahan ilustrasi/elemen sumber.
- `preview/`: hasil pratinjau.
- `final/`: hasil final yang telah disetujui.

Nama file disarankan: `page-XX-topik-v01.png`. Jangan menimpa versi final tanpa mencatat perubahan.
